# Kaju Goals Android workspace

This public repository is defining and building an original, production-quality Android goals app. The product name, application ID, and final scope are intentionally still open; current work is focused on research, product definition, and visual validation before implementation.

## Current status

- No Android application code has been created yet.
- The installed Goals product and leading goal/habit products have been researched.
- A product proposal and two visual explorations exist; the second is the active candidate.
- Durable context and decisions are maintained as Markdown in `docs/`.
